# Meme Sound Buttons for any website

Free, copy-paste **meme sound buttons** (a soundboard widget) for blogs, school projects, Notion-style
pages, streams and HTML sites. Each button is a tiny iframe: no JavaScript to install, no ads, no
tracking, no API key.

**Live demo:** https://mujahid11.github.io/meme-sound-buttons/

Sounds come from [Myinstants.net](https://myinstants.net/), a free meme soundboard with thousands of
instant sound buttons.

## Quick start

Paste this where you want the button:

```html
<iframe src="https://myinstants.net/embed/?id=542c49ac-1822-4abc-9c6b-d4c5dc43eca8&name=windows-xp-donteflon" width="320" height="96" style="border:0" loading="lazy" title="Windows XP sound button"></iframe>
<p style="margin:4px 0 0;font:13px sans-serif"><a href="https://myinstants.net/memesounds/542c49ac-1822-4abc-9c6b-d4c5dc43eca8/windows-xp-donteflon/">Windows XP</a> on Myinstants.net</p>
```

That's it. The button plays the sound on click and works on phones.

## Any sound

1. Open any sound on [myinstants.net](https://myinstants.net/myinstants/memesoundboard/) (or
   [search](https://myinstants.net/search/)).
2. Scroll to **Embed this sound on your site** and press **Copy embed code**.

Or build the URL yourself: `https://myinstants.net/embed/?id=<sound id>&name=<slug>`, taking both
parts from the sound page URL `https://myinstants.net/memesounds/<sound id>/<slug>/`.

## Options

| | |
|---|---|
| Size | Change `width` (min ~240) and `height` (96 fits the card). |
| Several buttons | Paste several snippets; each iframe is independent. |
| Markdown sites | Use the HTML snippet where your platform allows HTML; otherwise link the sound page. |
